# pair-wise-yf-55 动态表单规则编排和版本迁移模拟器

## 源提示词摘要
业务人员拖拽字段、设置分组、联动条件、计算规则、必填逻辑和多语言文案；发布前模拟旧数据在新结构下的迁移。系统比较版本差异，警告失效规则、循环依赖和引用删除，同时按历史版本解释过去提交的数据。

## 技术栈
React 19 + TypeScript + Vite + MUI + Redux Toolkit + RTK Query + React Router + React Hook Form + Zod + i18next + dnd-kit。

## 已实现闭环
- 表单版本、字段、联动规则和旧数据快照等业务对象。
- **草稿与修订号**：编辑只留在草稿，发布后才成为新版本；顶部「已发布修订号 rN」标识当前已发布结构。
- **协作者先发布检测**：模拟协作者发布后，本地草稿因修订号落后而标记为「已过期」，过期内容进入「待合并草稿」，已发布结构继续只读可查。
- **待合并草稿**：以最新已发布结构为底，合并旧草稿中仍兼容的字段与规则，生成基于最新修订号的新草稿。
- **发布前重查**：按最新结构重查历史快照，缺必填字段的记录进入迁移待办；旧数据的版本来源迁移为指向当前版本的兼容记录（原快照冻结保留）。
- **发布事务与回滚**：发布前保存回滚点，写入失败时恢复到上一个可用版本，并提示错误与回滚。
- **草稿恢复**：未完成草稿持久化到 localStorage，重新打开后恢复编辑并提示。
- **同一份已发布内容**：运行态表单与版本差异都读取当前已发布版本；不接后端，不新增依赖。
- 字段拖拽排序、新增字段、添加联动规则、发布新版本。
- 新旧版本差异、失效规则/循环依赖/引用删除警告、旧数据迁移缺口模拟。
- 运行态动态表单、跨字段校验和历史版本解释。
- localStorage 持久化。
